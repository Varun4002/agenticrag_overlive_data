Question answering lives in the Ask tab. These are the ingestion and indexing controls.

Seed fixture corpus

Upserts fixtures/corpus (44 synthetic documents) with deterministic ids. Idempotent; refused in prod. Then run a backfill to chunk and embed them.

Source sync

Runs connectors.service.sync — the same code path as scripts/sync_jira.py — for whichever source is selected. jira needs JIRA_* credentials; gmail needs GMAIL_ADDRESS and GMAIL_APP_PASSWORD (IMAP); notion answers 501, not implemented yet. Requires a database and network access to the source.

Embedding backfill

Chunks and embeds documents via Indexer. Bounded to 500 documents per click and 240 s wall clock. fake writes deterministic vectors and makes no provider calls — useful to exercise the pipeline offline.

Answer cache

Calls POST /admin/cache/invalidate: cached answers are keyed per user, so this drops all of them and bumps the data version so no entry written against an older version can be read again. With REDIS_URL unset the answer cache is disabled and the call reports that instead of failing.
